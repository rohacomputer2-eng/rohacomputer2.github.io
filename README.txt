Roha Computer Solution - run it
1. Install Node.js (https://nodejs.org)
2. In this folder run:  npm install
3. Run:  JWT_SECRET=your-long-random-secret npm start      (Windows: set JWT_SECRET=... then npm start)
4. Open http://localhost:3000 - first time, create the owner email + password.
To put it online: deploy this folder to Render, Railway or a VPS (keep roha.db on a persistent disk).
